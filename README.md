# বাংলাদেশ ফ্যামিলি কার্ড বাদ-পড়া পরিবার মাঠপর্যায় সার্ভে (PWA)
# Bangladesh Family Card Excluded-Household Field Survey PWA

একটি সম্পূর্ণ অফলাইন-ফার্স্ট এবং মোবাইল-অপ্টিমাইজড প্রগ্রেসিভ ওয়েব অ্যাপ্লিকেশন (PWA), যা বাংলাদেশ ফ্যামিলি কার্ড তালিকা থেকে বাদ পড়া পরিবারগুলোর তথ্য মাঠপর্যায়ে সংগ্রহের জন্য তৈরি।

## মূল সুবিধাসমূহ (Key Features)

- **১০০% অন-ডিভাইস অফলাইন ওসিআর (Tesseract.js Best)**: কোনো এক্সটার্নাল এআই কি বা ইন্টারনেটের প্রয়োজন নেই। ব্রাউজারের ভেতর সম্পূর্ণ অন-ডিভাইসে এনআইডি কার্ডের ছবি থেকে নাম এবং ১০/১৩/১৭ ডিজিটের এনআইডি নম্বর স্বয়ংক্রিয়ভাবে শনাক্ত হয়।
- **জিরো ডাটা লস ও অটো-সিঙ্ক**: ইন্টারনেট বিচ্ছিন্ন অবস্থায়ও তথ্য ব্রাউজারের IndexedDB-তে স্থায়ীভাবে সংরক্ষিত থাকে এবং ইন্টারনেট আসামাত্র ব্যাকগ্রাউন্ডে গুগল শিট ও ড্রাইভে আপলোড হয়।
- **ফিল্ড জিপিএস ট্র্যাকার**: কোনো জটিল ল্যাট/লং ছাড়া মাঠপর্যায়ের নির্ভুল গুগল ম্যাপস লিঙ্ক (`https://www.google.com/maps?q=lat,lng`) তৈরি করে।
- **ডুপ্লিকেট সুরক্ষা**: পূর্বে এন্ট্রি করা কোনো এনআইডি সাবমিট করলে আগের সিরিয়াল ও এলাকাসহ সতর্কবার্তা দেখায়।
- **ক্যাশড লিস্ট ও সার্চ**: পূর্বে সংরক্ষিত পরিবারগুলোর তথ্য অফলাইনেও লোকাল ক্যাশ থেকে দেখা যায়, এলাকা অনুযায়ী ফিল্টার করা যায় এবং এক ট্যাপে এনআইডি নম্বর কপি করা যায়।

## ডিপ্লয়মেন্ট গাইড (Vercel Deployment)

এই প্রজেক্টটি Vercel-এ ডিপ্লয় করার জন্য প্রস্তুত। **কোনো GEMINI_API_KEY বা বিলিং প্রয়োজন নেই!**

### ১. এনভায়রনমেন্ট ভ্যারিয়েবল সেটআপ (Environment Variables)
Vercel Dashboard-এ প্রজেক্ট ইমপোর্ট করার পর **Settings > Environment Variables** সেকশনে শুধুমাত্র একটি ভ্যারিয়েবল যোগ করুন:

| Variable Name | Description |
| :--- | :--- |
| `APPS_SCRIPT_URL` | গুগল অ্যাপস স্ক্রিপ্ট ওয়েব অ্যাপ ডিপ্লয়মেন্ট URL (`https://script.google.com/macros/s/.../exec`) |

### ২. লোকাল ডেভেলপমেন্ট
```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করুন।
